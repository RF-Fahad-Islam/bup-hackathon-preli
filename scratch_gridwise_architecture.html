System architecture — GridWise

Plain-English notes in. A proven-optimal 24‑hour energy plan out.

GridWise turns 1–3 free-text operator notes plus a day of demand/solar/tariff data into a cost-minimal grid+solar+battery schedule. Four stages do the work — a language model that reads, plain code that checks, a linear-program solver that plans, and plain code that audits — and none of them is trusted blindly by the next.

FastAPI + Pydantic v2 Groq → OpenRouter chain SciPy / HiGHS linear program ~1s median end-to-end 10/10 official samples, exact cost
01

The request pipeline

One POST to /optimize-energy passes through seven stages in order. Every stage's output is the next stage's untrusted input — nothing downstream assumes an upstream step got it right.

02

Inside the Reader: cheap model, tripwire, escalation

All notes in a request are read in one batched call. A pattern-based Tripwire never answers on its own — it only checks the LLM and forces a second opinion when they disagree.

03

Guardrail: why the LLM never does arithmetic

The model reports only what a note literally says — a Raw Reading. Code, not the model, expands hours and computes factors, which structurally eliminates the two classic failure modes.

Every note maps to exactly one of these six. When two notes overlap on the same hour, the most restrictive value wins: lowest solar factor, highest reserve, lowest grid cap, and no-charge/no-discharge hours simply union.

04

Planner: a two-stage linear program

120 variables — grid, solar used, charge, discharge and battery level for each of 24 hours — solved twice by HiGHS.

05

What happens when something fails

Every failure mode has a named, bounded response — nothing silently guesses.

FailureResponse
Cheap model misreads a noteTripwire disagrees → escalates to strong model, which is final
LLM returns invalid outputGuardrail rejects it; note escalates; invalid output never reaches the optimizer
A model is rate-limited (429)Only that model skipped for its Retry-After (max 30s); next in chain tried
A provider rejects the key / is downWhole provider skipped 5 min; falls through to OpenRouter
Strong model unavailableCheap reading used if it passed the guardrail — not cached
Every LLM unavailableDegraded Mode if Tripwire read every note confidently, else 502
Notes lead to an impossible planCached reading dropped; strong LLM re-reads once; still impossible → 422
Plan fails final replayControlled 500 — a wrong plan is never sent
